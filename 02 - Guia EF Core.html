Estados no EF Core

O que o Entity Framework faz com os seus objetos

Antes de gravar no banco, o EF Core anota o que aconteceu com cada objeto: se é novo, se mudou, se deve ser apagado. Essa anotação se chama State. Vamos ver quem anota, como anota e o que acontece quando você salva.

1O que é o DbContext

O DbContext é a classe que fica entre o seu código C# e o banco de dados. Pense num garçom: você faz os pedidos para ele, ele anota tudo num caderninho e só leva à cozinha quando você fecha o pedido. Clique em cada parte para ver onde ela aparece no código.
